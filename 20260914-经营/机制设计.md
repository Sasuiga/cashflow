

# 基本设定

- 一局的周期：一回合代表一个月，12个月一整局
- 游戏结束：
    - 特殊：当月结算后，净资产为负，宣告破产
    - 正常：未出现破产玩完12个月

# 玩法：

- 每月开始时会弹出
    - 固定行业信息：原材料价格、各类产品市场价格
    - 随机事件：对公司财务数据各方面产生影响，需要玩家做选择应对

- 完成随机事件应对后，进入本月的玩家行动环节
    - 玩家根据当前公司情况：财务数据、业务数据，选择行动
    - 每回合有基础行动点，一个行动消耗一次行动点



# 玩家行动


## 基本行动

- 决策1：产线建设
    - 购买设备：
        - 每台设备带来基础产能N点
        - 每台设备可以安置N个生产工人，随着工人的增加，产能增加
    - 扩建厂区
        - 一个厂区可以放置N台设备
- 决策2：人员招聘
    - 四类人员：生产、管理、销售、研发
    - 招聘每类人员的效果有2种：
        - 基础：
            - 生产：提升产能+与设备配合
            - 管理：提升决策点
            - 销售：提升需求
            - 研发：实施研发项目，每2个月研发出一款新产品（需求、价格、bom成本结构）
      - 进阶：特定类型人数越多，相关类型决策卡牌的出现概率越大‘
- 决策3：原料采购
    - 玩家能看到自己能销售的产品的bom，根据bom、产能来选择采购的种类、数量
    - 有3种基础原材料，组合成3种产品，对应低端、普通、高端3种
    - 原材料价格每月可能变动
    - 研发可能研发出新的产品结构，以更低的成本获得更高的收益，也可能解锁新的原材料，获得更多的需求等等
- 决策4：融资
    - 根据设备数量决定能融资的上限。

## 卡牌行动

当解锁卡片之后，增加卡片行动：

- 决策5：抽卡并选购（不消耗AP）

    - 卡牌类型出现概率受员工类型数量影响
    - 手牌有上限

- 决策6：打出卡牌

## 结算活动

- 决策7：生产销售安排：（不消耗AP）
    - 每月只能生产销售一种产品
    - 生产和销售，根据库存原材料、销售产品策略选择自主完成

- 决策8：点击结算按钮进行当月结算（不消耗AP）
