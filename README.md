# CASHFLOW · 十二个月

一局十二个月的单人经营桌游网页 Demo，按手机竖屏来玩。每季度开董事会定一条挑战，每月先看事项、再接单、再补缺口。净资产为负即破产。

## 本地运行

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可开局。

```bash
npm run build
npm run preview
```

## 这一局在玩什么

- **时间**：1 回合 = 1 个月，共 12 个月
- **董事会**：每季选 1 条挑战目标
- **事项**：每月一张。硬扛全额，或花 3 万缓一档
- **决策卡**：开局就能刷新。每月第一次免费翻 3 张，再刷新花 1 万；买入只花现金；打出耗 1 点行动点
- **接单**：可以超出现有产能去接。牌面给出料价毛利（未计人工）。锁定后交不出，整张违约，按件罚 0.5 万
- **补缺口**：采购、招聘、买设备、借款、打牌。系统只显示产能和料差，不告诉你该按哪个按钮
- **结束**：结算后净资产为负破产；撑过 12 月按生存、董事会考核和净资产评级

金额单位为万元。常见数字按 0.5 / 1 / 2 / 5 / 10 设计，方便口算。
