# CASHFLOW · 十二个月

一局十二个月的单人经营桌游网页 Demo。每季度开董事会定目标，再看行情与本月事项，花行动点经营，月末只排一种产品。净资产为负即破产。

## 本地运行

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可开局。

```bash
npm run build
npm run preview
```

## 这一局在玩什么

- **时间**：1 回合 = 1 个月，共 12 个月
- **开市**：原料价、成品市价与需求
- **事件**：每月一张，二选一
- **行动点**：基础 2 点，每名管理人员 +1
- **基本行动**：买设备、扩厂、招生产/管理/销售/研发、按 BOM 采购、按设备数融资
- **提案**：一月起每月出示三份，编制影响类别。每月可免费立项一份，次月落地时支付费用和 1 点行动点。待执行有上限，满了可替换。
- **产销**：每月只排一种产品
- **结束**：结算后净资产为负破产；撑过 12 月按净资产评级

金额单位为万元。常见数字按 0.5 / 1 / 2 / 5 / 10 设计，方便口算。
