# CASHFLOW · 十二个月

一局十二个月的单人经营桌游网页 Demo。每季度开董事会定目标，再看行情与本月事项，花行动点经营，月末只排一种产品。现金为负即破产。

## 本地运行

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可开局。

```bash
npm run build
npm run preview
```

## 这一局在玩什么

- **时间**：1 回合 = 1 个月，共 12 个月
- **开市**：每季抽一张本季定调（八种气候），管价格走势、现货配额、订单结构和本季产能/需求。月度事件仍按利好/利空/参半均等抽，气候只轻微偏向同主题卡面。
- **事件**：每月一张纯随机事项。先抽利好 / 利空 / 参半（三类均等），再从对应卡池抽一张。连出利好后，下一次利好权重略降，直到抽到利空才重置；参半不改其他类型权重。
- **行动点**：基础 2 点，每名管理人员 +1
- **开局**：现金 18 万，一台设备、一名生产工，无办公室编制
- **基本行动**：买设备、扩厂、招生产/管理/销售/研发/采购、按 BOM 采购、按设备数融资
- **提案**：一月起每月出示三份起，管理人员加出示、手牌和每月立项份数。编制影响类别。立项免费，次月落地耗 1 点行动点。待执行有上限，满了可替换。
- **编制流派**：销售跟进原料涨价，采购降加价伤害并可锁价，生产满机位后有弹性和连班，研发工艺同时只生效 2 项
- **产销**：每月只排一种产品
- **结束**：结算后现金为负破产；撑过 12 月按生存、董事会与账面净资产计分（现金或净资产为负时净资产项记 0）

金额单位为万元。常见数字按 0.5 / 1 / 2 / 5 / 10 设计，方便口算。
