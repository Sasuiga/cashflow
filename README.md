# CASHFLOW · 十二个月

一局十二个月的单人经营桌游网页 Demo。机制来自 `20260914-经营/机制设计.md`：看行情、应对事件、花行动点做决策，再安排当月唯一产品的产销并结算。净资产为负即破产。

## 本地运行

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可开局。

```bash
npm run build
npm run preview
```

## 这一局在玩什么

- **时间**：1 回合 = 1 个月，共 12 个月
- **开市**：原料价、成品市价与需求
- **事件**：每月一张，二选一
- **行动点**：基础 3 点，每 2 名管理人员 +1
- **基本行动**：买设备、扩厂、招生产/管理/销售/研发、按 BOM 采购、按设备数融资
- **卡片**：3 月或编制满 6 人后解锁。翻牌不耗 AP，选购耗现金，打出耗 1 AP。卡类权重跟员工结构走
- **产销**：每月只排一种产品
- **结束**：结算后净资产为负破产；撑过 12 月按净资产评级

单位为「千元」，界面按万元显示。
